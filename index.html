MHA Jury Defense Matrix & Architecture

Comprehensive Edge-Case Resolutions for SIH26184 Problem Statement
Defense Case 01

Non-Banking Node Routing (Crypto Exchanges / E-Wallets)

Challenge: Criminal syndicates funnel stolen funds into Virtual Asset Service Providers (WazirX, CoinDCX) or merchant wallet nodes instead of standard ATMs.

FORTIVEXA Resolution: Integrates FIU-IND compliance descriptors with VASP APIs. When Is_Crypto_POS_Node = 1, an automated API freeze notice with the compliant UTR token is dispatched instantly.
Defense Case 02

Delayed Cash-Out Strategies (2+ Days Delay)

Challenge: Syndicates intentionally sit on funds for 48 hours to evade immediate PCR patrol response windows.

FORTIVEXA Resolution: Employs Temporal Graph Neural Network (TGNN) holding time decay models. As Time_Lag_Mins exceeds 120 minutes, alerts dynamically pivot to bank lien requests and CCTV retrospective audits.
Defense Case 03

Merchant POS & Jewellery Redirection

Challenge: Stolen funds used to purchase gold bullion or luxury items at merchant points of sale.

FORTIVEXA Resolution: Fuses Merchant Category Codes (MCC 5944 Jewellery, 5541 Fuel). System shifts automatically to Geo-Merchant Alert Mode, warning commercial associations within a 3-km radius.
Defense Case 04

High Scalability & Zero System Crashing

Challenge: Nationwide scam spikes causing sudden floods of 100,000+ events per second.

FORTIVEXA Resolution: Decoupled microservices architecture using Apache Kafka message streaming, Apache Flink real-time windowing, and distributed graph traversals (< 20ms response time).
Defense Case 05

Mitigation of False Positives

Challenge: False alarms waste valuable police patrol fuel and beat officer time.

FORTIVEXA Resolution: Alerts trigger only when Risk Confidence > 80%. Instead of single-point speculations, a 3-km Spatial Radius Cluster is projected, allowing optimal beat-patrol positioning.
Defense Case 06

Spatio-Temporal Pattern Fusing

Challenge: Treating geographic ATM density and transaction timing in isolation yields misleading risk signals.

FORTIVEXA Resolution: Combines DBSCAN spatial density clustering with TGNN time-decay functions and ATM metadata (CCTV presence, lighting, isolation index) for multi-modal forecasting.
